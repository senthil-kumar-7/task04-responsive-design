# Task 04 - Responsive Design Tokens & Mobile-First CSS Architecture

This project demonstrates:
- CSS custom properties/design tokens for colors, typography, spacing and border radii
- CSS Grid and Flexbox
- Responsive breakpoints for 320px, 480px, 768px, 1024px and 1440px layouts
- Light/dark theme variables
- Hover transitions and soft shadows
- Mobile-first responsive behavior
- No horizontal scrolling
- Responsive demo screenshots in the `screenshots` folder

Files:
- `index.html`
- `style.css`
- `screenshots/`
